# Security Policy

## Supported Versions

Security updates are provided for the current `0.1.x` release line.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Use GitHub private vulnerability reporting to disclose a security issue. Do not
include genomic or patient data in a report.

This repository is a research pipeline, not a clinical interpretation tool. Security reports must not include protected health information or other sensitive data.

If private vulnerability reporting is unavailable, open a content-free issue
requesting a private reporting channel. Do not include vulnerability details or
sensitive data in the issue.
